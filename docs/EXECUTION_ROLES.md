# 规划与审核角色

此分工由用户指定，用于当前归档及后续民用场景工程阶段。本次仅执行归档，后续实现尚未开始；正式训练和评价需另行绑定执行包与预算。

| 角色 | 负责人 | 职责 |
|---|---|---|
| 执行器 | GPT-6 Luna | 本次起草归档文档；后续负责场景、接口、非学习对照及受控验收实现，记录待定项 |
| 独立审核 | GPT-6.1 Sol | 本次审核文档；后续检查实现合同、报告可见性、物资守恒和结果复算 |
| 阶段指挥 | 主对话 | 安排阶段、处理审核问题、确认交付标准；本次负责提交与远端核验 |

执行和审核时应遵守以下边界：

- 只围绕灾后巡查和药品、饮水等救援物资配送的独立民用应用。
- 本次归档不包含作战用途、目标选择、战术内容或实现代码。
- 将历史代码、历史场景和用户提供的运行回执与新场景证据分开。
- 对模型、数据、论文全文、凭据和授权材料不作公开归档或上传。
- 所有性能主张保持待验证状态，直至预先规定的对照和评估证据齐备。
