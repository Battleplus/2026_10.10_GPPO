# 研究计划 v1

## 目标与范围

规划一个独立民用多平台应用：灾后巡查，以及药品、饮水等救援物资配送。本文档记录研究与工程准备计划；本次仅归档文档，没有实施新场景或开展正式实验。研究协议须在工程验收及预算评估后、正式评价前冻结。

任务由两类需求组成：对指定点执行巡查（不是逐格覆盖整个地图），以及按取货、装载、运输、卸载和交付步骤完成物资配送。部分配送需求可能要由巡查报告发现。仿真真值可包含尚未发现的需求，规划器只能使用当时可见的巡查报告；训练、验证和报告必须保留这一信息边界。

## 暂定章节结构

1. **全局初始分配**：定义场景、可见信息、任务需求及初始任务归属和顺序，研究如何形成可执行的全局计划。
2. **局部扰动调整**：在计划执行中出现新报告、资源状态变化或任务受阻时，研究局部调整，并记录对既有任务和计划稳定性的影响。
3. **编队执行**：由第三章接收分配结果并研究编队执行，不包含在本次第二章工程范围中。

章节之间的实体与任务数量、任务定义、状态字段及划分方式必须统一。已确认地图为 10x10 格（共 100 格），2x2 局部块是暂定主设定；物理尺寸与坐标单位尚待统一。正式机群与任务数量目前未定，不能把示例参数当成已确认实验设定。

## 工程样例提案

建议先用合成、可复现的最小工程样例检查端到端接口：3 架无人机和 1 架直升机。该组合仅为合成提案，未实施，也不是第一章的真实输出或已验证结论。样例应显式区分仿真真值和可见报告，并包含指定点巡查及完整物资交付流程。

第一版只涉及物资，不涉及人员转运或医疗决策。巡查完成需要规定的观察服务与报告，配送完成需要卸载和交付确认；到点不能直接计为配送完成。已装载运输不直接换机，不模拟空中交接；无可行承接者的需求仍进入结果分母。

## 推进阶段

1. 场景合同和第一章接口样例：明确物资、任务生命周期、能力配置和可见报告。
2. 最小环境与两种非学习对照：保留初始分配，以及满足能力和库存约束的公开规则。未满足需求如实计入结果。
3. 真实生产路径工程验收：覆盖报告可见性、库存和载荷守恒、重复交付拒绝、故障及在途调整、区域外连带延误、结果复算和导出。
4. 依据实测耗时形成算法接入清单与正式预算，再分别安排基础 GPPO、世界模型附加价值及偏好控制验证。

后续工程阶段的交付目标是场景可运行、两种对照及受控验收完成。当前归档不代表这些工作已经实施，也不包含正式训练批准。

## 比较与证据

正式研究前应先固定统一场景接口和任务完成规则，通过工程验收，再建立非学习对照与评估划分。预算和可用资源评估后才能提出正式运行申请；本计划不指定确定的运行配额或时长。

证据至少应支持以下相互独立的问题：

- **泛化**：在预先定义且隔离的场景划分上评估，报告跨地图、任务组合及扰动条件的表现与不确定性。
- **偏好一致性**：预先说明偏好输入及对应的评价规则，检查输出是否依照偏好改变，并报告冲突和退化情形。
- **世界模型决策价值**：与明确的无模型或非学习对照比较，隔离模型带来的决策影响，并报告预测误差及其对任务结果的关系。
- **多目标质量**：若比较 PCRL，应按预注册协议报告其 HV、CS 等适用指标；不能以增加若干其他指标取代这些指标，也不能仅凭单一聚合分数宣称优势。

所有指标、基线、随机种子、划分、统计方法和停止规则应在实验前确定。结果应覆盖收益与重大损失等不同后果，披露失败案例和不确定性。未经这些证据，不得声称方法优越或可靠增益。
