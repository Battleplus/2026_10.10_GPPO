# 灾后巡查与救援运输：图强化学习与世界模型研究规划

本仓库记录第二章的场景迁移方案、实验规划和历史研究状态。研究对象是无人机与直升机组成的异构平台集群，任务限定为灾后指定点巡查和药品、饮水等救援物资配送。

**第二章的目标：接收第一章的初始区域及任务分配，在新增需求、平台失效、资源变化或信息延迟发生后，调整局部任务归属和执行顺序，并评估救援效果、调整代价和决策成本。**

更新日期：2026-10-11。当前交付为规划文档，新场景实现、工程验收和正式研究尚未完成。

## 章节接口与场景

| 章节 | 职责 | 与第二章的关系 |
|---|---|---|
| 第一章 | 全局区域分组及初始分配；其内部动态分配范围仍需统一 | 提供初始归属、任务顺序、平台状态和交接时刻 |
| 第二章 | 扰动后的局部任务再分配 | 输出修订归属、执行顺序、调整原因及未满足需求 |
| 第三章 | 根据分配结果研究编队执行 | 接收第二章输出，飞行编队控制由第三章处理 |
| 第四章 | 尚未确定 | 暂不假设其接口 |

地图按 10x10、共 100 个格组织。2x2 局部块是暂定方案，对应 25 个块；物理尺寸、最终平台数、能力参数和任务量仍需跨章统一。3 架无人机与 1 架直升机仅作为最小工程样例提案。

第一章尚无真实输出时，先使用标记为 `synthetic_initial_assignment` 的合成接口样例推进工程。真实接口到位后替换输入并复验，不将合成样例当作第一章成果。

## 方法要验证什么

| 方法部分 | 作用假设 | 必须通过的比较 |
|---|---|---|
| 图强化学习 | 表达平台、任务和区域间关系，在规模、布局或任务组合变化时保持性能 | 与相同信息和训练预算的非图策略比较，测试阶段不追加训练 |
| 动作后果世界模型 | 预测候选调整对本任务及其他任务的后果，改善决策 | 图策略加世界模型与同一图策略无世界模型配对比较，同时计入推理成本 |
| 偏好控制 | 在完成质量、延误、能耗和调整代价之间按输入偏好作出取舍 | 作为后续扩展单独验证，主比较使用固定偏好 |

这些是待检验假设。当前不能声称图模型已实现跨规模泛化，或世界模型已带来任务收益。

## 下一步交付顺序

1. **场景合同与合成输入**：统一单位、任务状态、报告可见性、异构能力和局部调整边界。
2. **最小可运行环境**：实现巡查报告及物资取货、装载、运输、卸载、确认全过程。
3. **两种非学习对照及工程验收**：保留原分配、公开约束规则再分配；验收守恒、失败路径、结果复算和导出。
4. **算法迁移与预算测量**：适配旧 W1 固定动作槽接线、补齐关系编码，记录实测耗时、存储和各阶段额度。
5. **冻结后开展对照实验**：先验证图策略，再验证世界模型附加价值；正式训练需绑定新执行包和预算。

当前优先交付第 1 至第 3 项。完整实验矩阵、指标和停止规则见[研究计划](docs/RESEARCH_PLAN_V1.md)。已归档[第二章执行方案 v1](docs/execution-v1/EXPERIMENT_PLAN.md)：首个目标是交付合成交接、可运行的民用最小场景、C0/C1 非学习对照、逐任务轨迹和独立复算，并经审核验收；这是工程目标，不保证算法收益。

## 已有工作与结论边界

根据用户于 2026-10-10 提供的历史 v7 回执，排序归一化 A/B 三种子共完成 1,920 次更新，保存六个 checkpoint，账本记录六次加载。加载计数不能证明六路严格恢复全部通过。该次作业在 heldout 环境构造处因 `KeyError('scenario')` 技术停止；这是原始运行的历史状态。

2026-10-11 的本地恢复报告记录 B−A regret 为 +0.000752792，95% CI [-0.003627776,+0.007082811]，不支持窗口等权优势。原始 `technical_stop` 仍记录那次运行的工程停止，不覆盖后续本地恢复评价；本次没有重新远端取证。

旧多头标签、候选合同、排序损失、replay 和资源账本可作为迁移起点。根目录 `src/uav_assignment/paper_faithful_models.py` 有可复用图算子；4 平台、6 任务槽、25 动作是旧 W1 接线的固定约束，不能据此描述根目录图算子或证明异构可变规模图调度已实现。

## 范围与证据边界

当前研究对象是民用灾后任务规划。任务包括指定点巡查（不要求整格覆盖）和物资运输（取货、装载、运输、卸载、交付）。部分物资需求可由巡查报告发现，因此模拟器内部真值与决策者可见报告必须分开记录。

历史简化调度场景的代码及结果不能直接作为上述新场景的有效性证据。本归档记录的 v7 训练回执由用户于 2026-10-10 提供；本次未复核远程原始制品。所有研究主张均为待验证，不声称方法优越性。

本次交付仅为文档归档，未执行新场景实现、训练或评价。后续工程分工见执行角色文档；正式研究运行需另行绑定执行包和预算。本次不上传模型、数据集、论文全文、凭据或授权材料。
