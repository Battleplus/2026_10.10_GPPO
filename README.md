# GPPO 研究规划归档

本仓库保存面向独立民用应用的研究规划、状态和交接要求，不包含算法实现，也不构成正式研究或运行授权。应用范围限定为灾后巡查，以及药品、饮水等救援物资的配送。

## 文档

- [研究计划 v1](docs/RESEARCH_PLAN_V1.md)：研究问题、章节安排、假设与证据要求。
- [研究状态](docs/RESEARCH_STATUS.md)：已知回执、工程现状和未完成事项。
- [交接要求](docs/HANDOFF_REQUIREMENTS.md)：已知接口、待定字段及阶段门槛。
- [执行角色](docs/EXECUTION_ROLES.md)：规划、审核和阶段指挥职责。

## 范围与证据边界

当前研究对象是民用灾后任务规划。任务包括指定点巡查（不要求整格覆盖）和物资运输（取货、装载、运输、卸载、交付）。部分物资需求可由巡查报告发现，因此模拟器内部真值与决策者可见报告必须分开记录。

历史简化调度场景的代码及结果不能直接作为上述新场景的有效性证据。本归档记录的 v7 训练回执由用户于 2026-10-10 提供；本次未复核远程原始制品。所有研究主张均为待验证，不声称方法优越性。

本次交付仅为文档归档，未执行新场景实现、训练或评价。后续工程分工见执行角色文档；正式研究运行需另行绑定执行包和预算。本次不上传模型、数据集、论文全文、凭据或授权材料。
